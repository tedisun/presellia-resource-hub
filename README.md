# Presellia Resource Hub

Plugin WordPress officiel pour l'espace Ressources de Presellia (Tedisun SARL).

Ce plugin permet de gérer et de diffuser des ressources gratuites ou semi-fermées (guides PDF, scripts PowerShell/outils de diagnostic, fichiers d'installation officiels, templates) avec :
- Un catalogue public immersif et responsive avec filtres et recherche instantanée (`/ressources/`).
- Des pages de ressources uniques inspirées du style Alex Hormozi (fort taux de conversion, zéro distraction, headline axée résultat, stack de valeur).
- Une capture de leads direct via l'API native de **FluentCRM Pro** (Prénom, Email, Téléphone/WhatsApp).
- Une box d'offre complémentaire irrésistible connectée à **WooCommerce**.
- Une API REST MCP sécurisée (`/wp-json/prh/v1/`) permettant aux agents IA d'interagir, auditer et créer des ressources de façon autonome.

## Installation
1. Télécharger le fichier ZIP depuis les [Releases GitHub](https://github.com/tedisun/presellia-resource-hub/releases).
2. Aller dans l'administration WordPress > **Extensions** > **Ajouter**.
3. Téléverser le fichier ZIP et cliquer sur **Activer**.

## Prérequis
- WordPress 6.0+
- PHP 8.0+
- WooCommerce (optionnel mais recommandé pour les offres croisées)
- FluentCRM Pro (pour la capture de leads et segmentation)
